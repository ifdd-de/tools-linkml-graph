# Changelog

All notable changes to this project are documented in this file. Versions
follow Semantic Versioning.

## [0.1.5] - 2026-11-17

First release from `ifdd-de/tools-linkml-graph` (tag `v0.1.5`). Earlier
changes in `mleist/linkml-graph-explorer` are not recorded here.

### Changed
- The repository moved to the GitHub organisation `ifdd-de` as
  `tools-linkml-graph`; links point there. Package and command names stay
  (`linkml-graph-explorer`, `graph-explorer`).
- License holder and package metadata follow the `ifdd-de` conventions
  (author Markus Leist, maintainers `ifdd.de contributors`).
- CI runs on Python 3.10 to 3.14.

### Added
- License texts of the bundled layout-base and cose-base.
